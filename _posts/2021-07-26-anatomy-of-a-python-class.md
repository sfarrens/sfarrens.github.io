This tutorial gives a behind-the-scenes look at how Python classes work, covering both introductory and more advanced topics. It was originally prepared for [EuroPython 2021](https://ep2021.europython.eu/).

The first part covers foundational topics:

- Methods
- Properties
- Operator overloading

The second part introduces more advanced concepts:

- Inheritance
- Composition
- Abstract classes

Exercises are included throughout. The tutorial is aimed at intermediate Python users but is also accessible to beginners.
